# RigPulse v0.5.5

Nerd Console now behaves visually like an ASIC appliance interface rather than
a recolored web dashboard.

- Adds Rajdhani headings and Share Tech Mono telemetry typography.
- Adds purpose-built SVG icons for temperature, fan, power, shares, best share,
  uptime, pool, efficiency, rejected shares, and lifetime shares.
- Adds live circular gauges for miner temperature and fan speed.
- Uses off-green LCD hashrate displays with white and muted-green supporting text.
- Reduces repetitive neon borders in favor of a dark layered chassis.
- Improves miner-card headers, telemetry hierarchy, charts, and controls.
