# RigPulse v0.4.6

- Adds native BTC and BCH solo-mining probability calculations using live network difficulty.
- Supports separate BTC/BCH hashrates entered in TH/s or PH/s.
- Shows 24-hour, 7-day, and 30-day chances plus statistically expected solve time in the existing network boxes.
- Adds main-dashboard BTC/BCH SoloPool status with hashrate, online workers, last share, best share, and blocks found.
- Adds watch-only BTC and BCH SoloPool mining-address fields to Dashboard Customization.
- Extends pool-side block detection to configured BTC SoloPool accounts.
