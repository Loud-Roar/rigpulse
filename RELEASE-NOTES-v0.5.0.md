# RigPulse v0.5.0

- Adds a Hide Menu / Show Menu button that expands the dashboard to the full available width.
- Adds an Arrange mode for dragging dashboard boxes into a preferred order.
- Adds Normal, Wide, and Full width choices through each box's Resize control.
- Saves sidebar visibility, box order, and box sizes locally in the browser and restores them after reloads.
- Adds a Reset Box Layout action to Dashboard Customization.
- Shows the current USD equivalent beside configured BTC and BCH wallet balances.
