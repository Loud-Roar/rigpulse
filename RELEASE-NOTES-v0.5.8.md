# RigPulse v0.5.8

Emergency compatibility rollback for the v0.5.7 miner-card regression.

## Changes

- Restores the proven v0.5.6 miner-card structure across every theme.
- Restores normal typography, spacing, stat grids, graphs, and card actions in
  Midnight, Aurora, Bitcoin Orange, Matrix, Deep Ocean, and photo themes.
- Restores the established RigPulse Console card density.
- Preserves user settings, miner configuration, history, wallets, pools,
  block-found badges, and telemetry.
