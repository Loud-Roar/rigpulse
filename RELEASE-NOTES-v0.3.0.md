# RigPulse v0.3.0

First public RigPulse release, prepared for `github.com/Loud-Roar/rigpulse`.

## Release highlights

- RigPulse branding and local ASIC fleet monitoring dashboard.
- Multi-architecture Docker image publishing for amd64 and arm64.
- GHCR image: `ghcr.io/loud-roar/rigpulse:0.3.0`.
- Persistent `/data` storage for Docker and Umbrel.
- Automatic and manual migration support for the legacy v0.2.x database.
- Six dashboard summary cards remain on one row at normal desktop widths.
- Responsive three-, two-, and one-column layouts remain available on narrower screens.

The previously planned v0.3.1 desktop layout correction was folded into this
publication package so the first GitHub/Umbrel image includes it.
