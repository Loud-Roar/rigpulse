# RigPulse v0.6.0

- Replaces the large BTC, BCH, and ALPH dashboard blocks with compact market cards.
- Uses the supplied custom Bitcoin, Bitcoin Cash, and Alephium icons.
- Keeps only the icon, current USD price, 24-hour change, and LIVE status on each card.
- Opens detailed block, network, solo-mining, source, and wallet information when a coin card is clicked.
- Adds watch-only Alephium wallet balance tracking through the official mainnet explorer API.
- Adds the ALPH balance and calculated USD value to Public Wallet Balances.
- Adds an editable Alephium address field in Customization and preconfigures the supplied public address.
