# RigPulse v0.4.2

- Refreshes BTC and BCH wallet balances immediately after customization is saved.
- Isolates BTC and BCH lookup errors so one provider cannot hide the other balance.
- Replaces the rejected BCH balance request with the BCH Blockbook API.
- Accepts BCH CashAddr wallet addresses with or without the `bitcoincash:` prefix.
- Shows AxeOS/NerdOCTAXE accepted shares as the live **Current Shares** card value.
