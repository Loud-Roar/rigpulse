# RigPulse v0.5.3

This is a visual stability and wide-screen polish release for Nerd Console.

- Stops Pool Miners from flashing during automatic telemetry refreshes.
- Updates existing worker cards in place instead of rebuilding the whole grid.
- Fits more compact instrument cards across normal and ultra-wide desktops.
- Removes the empty decorative graph from SoloPool worker cards.
- Improves statistic label size, contrast, spacing, and card colors.
- Lets one configured SoloPool account use the full pool-status area.
