# RigPulse v0.5.6

RigPulse Console replaces the former Nerd Console presentation with the
approved contemporary miner-card direction.

## Changes

- Renames the visible Nerd Console theme to RigPulse Console.
- Replaces the condensed and monospace-heavy typography with a modern,
  screen-friendly font stack.
- Rebuilds each miner's green hashrate area as a dark emerald live instrument
  with luminous green figures, a clear label, and a restrained status glow.
- Softens miner cards, status chips, graphs, metrics, pool panels, wallet
  panels, and network panels with rounded contemporary surfaces.
- Retains existing telemetry, gauges, best-share highlighting, block-found
  badges, responsive behavior, and in-place refresh logic.
