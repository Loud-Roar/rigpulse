# RigPulse v0.5.4

This release refines Nerd Console around a cohesive OCTAXE-inspired palette.

- Replaces pale blue panels with black and charcoal appliance surfaces.
- Uses luminous green LCD readouts for primary mining values.
- Applies a condensed technical type treatment across the dashboard.
- Unifies pool, wallet, network, summary, navigation, and miner-card styling.
- Keeps yellow and red reserved for warnings and faults.
- Preserves the stable in-place pool refresh introduced in v0.5.3.
