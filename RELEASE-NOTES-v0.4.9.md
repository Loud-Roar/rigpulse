# RigPulse v0.4.9

- Adds live USD prices for Bitcoin (BTC), Bitcoin Cash (BCH), and Alephium (ALPH).
- Shows each asset's 24-hour percentage movement with positive/negative coloring.
- Embeds BTC and BCH prices in their existing block cards and adds a matching Alephium market card beside them.
- Caches the last successful values so a temporary external API error does not interrupt miner monitoring.
