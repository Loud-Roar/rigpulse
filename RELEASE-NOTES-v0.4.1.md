# RigPulse v0.4.1

- Adds read-only BCH SoloPool miner-statistics monitoring.
- Automatically discovers SoloPool addresses from pool worker usernames when available.
- Matches the pool's winning worker to a RigPulse miner card case-insensitively.
- Imports an already-found block once and avoids duplicate celebrations on later polls.
- Supports a manually configured public SoloPool mining address as a fallback.
